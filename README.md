# XR Medical Tabletop 🩺🥽

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

An interactive XR medical tabletop simulation developed in Unity using OpenXR and XR Interaction Toolkit for immersive medical learning, visualization, and training.

---

## 🌐 Accessibility

XR Medical Tabletop is designed to be accessible for students, researchers, developers, and educators interested in XR-based medical education and immersive learning technologies.

The project is open for:
- Educational learning
- Research purposes
- XR development exploration
- Medical visualization studies
- Academic demonstrations
- Portfolio and learning reference

The system focuses on intuitive interaction, immersive visualization, and easy accessibility for users exploring medical XR environments.
