# XR Medical Tabletop 🩺🥽

An interactive XR medical tabletop simulation developed in Unity using OpenXR and XR Interaction Toolkit for immersive medical learning, visualization, and training.

---

# 📌 Overview

XR Medical Tabletop is an immersive educational and simulation-based Extended Reality (XR) application designed to improve medical learning through interactive virtual environments. The project combines Virtual Reality (VR) interaction systems with tabletop-style visualization to create a realistic and engaging learning experience.

The system allows users to interact with medical objects, anatomical structures, and simulation environments using XR controllers and immersive interaction techniques. The application focuses on intuitive interaction, educational accessibility, and immersive visualization for training and demonstration purposes.

This project was developed using Unity, OpenXR, and XR Interaction Toolkit with optimization for Oculus Quest 2 and PC VR platforms.
